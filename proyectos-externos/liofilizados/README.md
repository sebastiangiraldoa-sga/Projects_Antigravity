# Proyecto Liofilizados
**Proyecto de Investigación / Aplicación Especial**

## Descripción
Proyecto enfocado en la tecnología de liofilización (liofilizadores, sistemas de vacío, refrigeración y condensación, control de temperatura y ciclos térmicos).

---

## 📌 Hitos y Salidas
- **[13 Nov 2026 - 08:00 a 12:30]**: Salida de campo para **levantamiento de equipos** en **Candelaria, Valle del Cauca**.
  - Objetivos sugeridos para la visita:
    - [ ] Identificación de modelos, marcas y capacidad de los liofilizadores / equipos periféricos.
    - [ ] Registro de especificaciones de vacío (bombas, sensores de presión Pirani/capacitivos).
    - [ ] Registro de sistemas de frío y condensadores (temperaturas mínimas de trampa).
    - [ ] Evaluación de estado operativo y sistemas de control/adquisición de datos.
    - [ ] Registro fotográfico y fichas técnicas.

---

## Estructura sugerida
- `fichas-tecnicas/`: Especificaciones de cada equipo levantado.
- `protocolos/`: Guías de operación y ciclos de liofilización.
- `reportes/`: Informes técnicos del proyecto.
